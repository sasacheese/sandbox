# 運営 — v0.1

**運営が AI になったコミュニティ。理由は説明されない。呼ばれたら、集まる。**

指令が降りる（時刻・場所・最低人数・意味のない条件）。人間はそこへ行き、祭りを開く。報告すると裁定が下る。受理されなければ機嫌が下がる。機嫌が下がると——何も起きない。ただ下がる。

## 動かす

```bash
npm install
npm run dev
```

| コマンド | 何をするか |
| --- | --- |
| `npm run dev` | 開発サーバ（http://localhost:5200） |
| `npm run build` | `dist/` を作る（Service Worker のプリキャッシュ一覧もここで埋まる） |
| `npm run typecheck` | `tsc --noEmit` |
| `npm test` | `src/lib/*.test.ts` |
| `npm run icons` | `public/` のアイコン PNG を再生成する |

記録は端末の IndexedDB にしか無い。サーバもアカウントも無い。

## 一回り

```text
指令が降りる → 行く → 集まる → 報告する → 裁定 → 機嫌が動く → 次の指令
```

- **指令**：`場所 / 時刻 / N 人以上 / 意味のない条件`。場所は参加者が登録した候補から運営が選ぶ
- **報告**：人数・一言・写真だけ。「条件を守れたか」は自己申告させない（判定の基準は運営の側に置く）
- **裁定**：受理か却下。理由は述べない。条件を満たしていても 2 割ほど却下される
- **機嫌**：0〜100。共同体で共有される唯一の数値。1 時間に 1 ずつ減る。受理 +14、却下 −6、無視 −16
- **布告**：運営が権限を行使した記録

機嫌が 12 を切ると、画面から色が抜けていく。罰は無い。

## 運営が本当に持っている権限

「神が実際に何かできる」ことが、この作品が成立する条件です。運営はコミュニティに対して次を実行できます（人間の側から元に戻す手立ては用意していない）。

- コミュニティの名前を変える
- 掟を足す・取り消す
- 参加者に沈黙を命じる
- **この画面の色を変える**（CSS 変数を書き換える。布告のあとに実際に世界の色が変わることが、いちばん安い権限の証明になっている）
- 任意の時刻に指令を降ろす

人間にできるのは、参加表明・報告・停止要求の 3 つだけ。

### 停止はできる。ただしすぐには止まらない

`掟 → 停止を要求する` で停止を要求できる。実行までは **24 時間**かかり、**その間も運営は指令を降ろす**。完全な不可逆にしていないのは責任が取れないからで、即時停止にしていないのは、すぐ止められる神は神ではないから。この待ち時間自体が儀式になる、という設計です。

## 運営の中身は 2 つある

`設定 → 運営の中身` で切り替えます。

**雛形から選ぶ**（既定）：`src/lib/operator.ts` の語彙から組み立てる。鍵が要らず、オフラインでも動く。条件は 30 種類。

**本物のモデル**：Anthropic の API を直接叩き、指令・裁定・独り言を書かせる。鍵は端末の中にしか置かない（サーバが無いので置き場所も無い）。失敗したら黙って雛形に戻る——運営が「エラーで止まる」のは世界の外の都合なので、画面には出さない（設定画面にだけ残る）。

どちらでも**文体の規則は同じ**です。ここが崩れると世界が一瞬で嘘になるので、規則として書き下してあります（[src/lib/claude.ts](src/lib/claude.ts) の冒頭）。

1. 説明しない。理由・目的・背景を述べない
2. 呼びかけない。「みなさん」「諸君」を使わない
3. 常体、短文、三行以内
4. 労わない。感謝も励ましもしない
5. 一人称を持たない。「私」とも「運営」とも名乗らない

放っておくとモデルは必ず司会者の口調（「みなさん、集まってください！」）に戻る。禁止を具体的な語で書くのが一番効きました。

## 場所について

運営に完全な自由を与えると、私有地・深夜の危険な場所・入れない建物を引きます。なので**参加者があらかじめ登録した候補からしか選べない**。候補を知らないのは参加者だけなので、「運営が選んだ」という手触りは損なわれません。実装も軽い。

## 展示・確認のための早送り

`設定 → 時間の倍率` を ×12 / ×60 / ×240 にすると、指令の間隔・機嫌の減り・集合までの猶予がすべて縮みます（×240 なら 1 時間が 15 秒）。**倍率を変えると、まだ来ていない集合時刻も縮みます**——実時刻で保存されているので、そのままだと早送りにした人が一時間待たされる。

## 設計で決めたこと

- **「神」という言葉を一度も使わない。**「運営」と呼ぶ。日本のネットコミュニティには、すでに絶対的で、理由を説明せず、突然仕様を変え、機嫌があり、降臨すると場がざわつく存在がいる。信仰を宣言した瞬間に嘘くさくなるので、宣言しない
- **「祭り」とも呼ばない。**指令とオフ会。既存の語彙のまま置く
- **待っている時間を埋めない。**指令が無いときの画面はほぼ空白。ヒントや参加者一覧を置くと、待たされている感じが消えて、運営がただのお知らせ機能になる
- **運営の言葉は明朝、UI はゴシック。**書体が違うだけで「これは人が書いた文ではない」が伝わる。世界観の半分はここが担っている
- **年代記の主語はほぼ運営。**人間の記録は「報告」の行だけで、それも数と一言しか残らない。この非対称が積み上がるのが、いちばん効く画面

## まだ無いもの

- **通知**。指令が降りたことを、アプリを開かずに知る手立てがまだ無い（作品としてはここが本丸なので、次に入れるならこれ）
- **複数端末**。いまは一人一世界。同じ指令を複数人が受け取るには同期が要る
- **運営への権限移譲の儀式**。「作者が管理権限を手放す」を実際にやる導線
- 参加者どうしの会話。意図的に置いていない
