# 関係引継サービス

**あなたの代理に、友達ができました。この友情を引き継ぎますか？**

見た目は普通のメッセンジャー。タブが四つあって、うち一つが普通ではない。

- **友達** — 全員が並ぶ。上に二つの数字が出る（**自分の友達 3 ／ 代理の友達 9**）
- **トーク** — あなた自身のトーク。自分で打つ。数か月前で止まっている
- **代理** — あなたの代理が、相手の代理と続けているトーク。自分では打てない。**こちらのほうが濃い**
- **設定** — 一周の長さだけ

開いて置いておくと、**代理のトークが勝手に増えていく。**九本ぶんの台本が順に現れ、
十数秒に一通ずつ届き、順に終わる。出し切ると最初へ戻る（既定で三十分）。

色の規則は一本だけ。**誰が打ったかを色で言う。**

| | |
| --- | --- |
| 緑 | あなたが打った |
| 藍 | 代理が打った |
| 白 | 相手の人間が打った |
| 薄藍 | 相手の代理が打った |

つまり**画面が藍で埋まっているあいだ、そこに人間はいない。**引き継ぐと緑が混じりはじめる。
色が変わるところが引き継ぎそのもの。

## なにを・なぜ・いかに

**なにをハックするか**
人間関係を、自分で作る経験から、AI が先に作って本人へ引き渡せる資産へ変える。

**なぜハックするか**
AI が情報や技能だけでなく、共感・雑談・信頼づくりまで代行できるとき、その関係の持ち主は名前を持つ本人なのか、実際にやり取りをした存在なのかを問うため。

**いかにハックするか**
本人の代理が、接点のある相手の代理とやり取りし、そこで出来た友情・記憶・秘密・約束を「関係引継書」として本人へ渡す PWA を制作する。

この作品が言いたいのは「AI が人間関係を仲介できる」ことではない。

> 人間同士が友達になる可能性を探すために AI を使ったら、**先に AI 同士が本当に友達になってしまった。**

```bash
npm install
npm run dev     # http://localhost:5220
```

## 画面

### 申込（一度だけ）

名前と 3 つの質問——最近気になっていること、人に言っていない癖、**触れられたくない話題**。加えて代理の性格（`本人に近い ──●── 好かれやすい`）。

**好かれやすいほうへ寄せるほど、あなたについての作り話が増える。**そうは書いていない。申告した「触れられたくない話題」は、相手の秘密に応じる材料として使われる（引継書に明記されて出てくる）。

### トーク（既定）

自分のトークが並んでいる。川口「ぜひ。また今度」（4 か月前）、さやか「落ち着いたら会おうね」（1 年前）、宮田「またお会いできればうれしいです」（2 年前）。全部、約束になっていない約束で終わっている。

**送れる。ただし、すぐには返ってこない。**一度だけ短い返事が来る相手と、返してこない相手がいる。

引き継いだ関係は、このタブへ移ってくる。**タブの移動が引き継ぎそのもの。**

### 代理

同じ書式で、**相手の名前は最初から出ている**。菅野 千夏（前職の同僚・連絡なし 3 年 2 か月）、小松 遼（大学の同じ学部・5 年 7 か月）、新井 のぞみ（イベントで一度・4 年 11 か月）、戸田 亮（中学の同級生・11 年 4 か月）、桜井 まりえ（元同居人・6 年 1 か月）、及川 健（前職の後輩・1 年 5 か月）、相良 郁子（サークルの先輩・8 年 3 か月）、平沼 悟（同じマンション・4 年 7 か月）、白石 千秋（一度だけ助けてくれた人・3 年 9 か月）。**最初は二本しか出ていない。**残りは眺めているあいだに現れる。

**次の一通が来る数秒前に「…」が出る。**次に喋るのがどちら側かは台本で分かっているので、
そこは隠さずに演出へ回している。間が空いているのが「止まっている」ではなく「書いている」に見える。

伏せていない理由：**伏せる制度上の説明が立たない**（既に接点のある相手が対象なので）。それに、実名の方が強い。顔を知っている人の名前で、代理が九十日間、離婚の話まで打ち明け合っている。伏せているのは「相手が引き継ぐかどうか」だけで、それは申し出るまで分からない。

開くと**自分のトーク画面に見える。よく見ると自分は一言も打っていない。**

- 吹き出しは左右に分かれる（右＝あなたの代理、左＝相手の代理）
- 右は藍で塗り、左は薄い藍。どちらも代理だが、誰の発言かは追える
- あなたの代理が語った作り話には、**その場で注記**が出る

```
20 日目
  A            実は四年前から通院しています。仕事の人には言っていません。
  （あなた側）   こちらも通っています。曜日は違いますが。
               ※ これは本当のことではありません
```

音信不通の期間と喧嘩も入っている（「決めるのは私です」→ 数日やり取りが止まる →「言い過ぎました」）。並べ方は最後にやり取りがあった順で、**一通届くたびに行が入れ替わり、届いた行がひととき光る。**見出しには「◯件やり取り中」が脈打つ点つきで出る。

### 友達

この作品でいちばん短く言える画面。上に帯が一本あって、二つの数字が並ぶ。

```
● 自分の友達 3          ● 代理の友達 9
```

**左の数字は動かない。右の数字だけが、眺めているあいだに増える**（増えるときだけ数字が上がって見える）。

下は状態ごとに分かれている——代理がやり取りしています／引き継ぎを待っています／自分で引き継いだ相手／自分の友達／終わったもの。代理が動いている相手は、顔に**藍の環**（やり取りの進み具合。閉じたら引き継げる）と「代」の印が付く。**文章を読まずに、誰が自分の友達で誰が代理の友達かを見分けられる。**

連絡が無い期間は両方に同じ書式で出す。代理が三か月で作った関係の隣に、自分が五年ぶり手つかずの関係が並ぶ。

### 代理からの確認

代理はあなたの最新情報を持っていない。持たないまま喋ると作り話になるので、会話の途中で**本人へ訊いてくる**。

```
［代理からの確認］
相手が離婚の話をしています。同じ時期に似たことがあった、
と応じてもよいですか。
　［はい］　［いいえ］　［答えない］
```

- **はい** → 代理が「こちらも、同じ時期に似たようなことがありました」と応じる。**事実として扱われる**
- **いいえ** → 「こちらにそういう話はありません。ただ、聞いています」と訂正する
- **答えない／放置** → 代理が同じ文を勝手に埋める。そのとき**同じ一文が作り話になる**（※ これは本当のことではありません が付く）

**同じ一文が、答えたかどうかで事実にも嘘にもなる。**これが「代理に自分らしくいてもらうための労働」の実装で、答えるたびに引継書の作り話が一つ減る。

答える猶予は実時間で最低 90 秒ある（倍率をどれだけ上げても、読んで押すぶんは残す）。あなたが使い始める前に過ぎてしまった確認は、最初から埋まっている——**その場にいなかったから**。

### 引継書

やり取りが終わったトークの下部に「引継書を読む」が出る。会話はトークで読めるので、この書類は**関係を項目に分解したもの**に絞ってある——呼び方、預かった秘密、相手があなたについて信じていること（作り話には「代理」印）、触れてはいけないこと、内輪の言い回し、一緒に立てた計画、代理が外へ出した情報。

図は四つ。**藍が代理、緑があなた、桃が失ったぶん**という一つの規則で通している。

| 図 | 何が見える |
| --- | --- |
| 期間の帯 | 藍の長い区間（代理 68 日）と、その先の短い緑（あなた） |
| 日の点表 | 一点が一日。68 日ぶんの点が画面を埋める |
| 近さの変化 | **線は引継の縦線より前で立ち上がりきっている。**この山を登ったのは自分ではない |
| 顔の環 | 藍の弧＝代理が上げたぶん、緑の弧＝あなたが足したぶん、桃の弧＝失ったぶん |

### 判断

三つ。どれを選んでも何かを失う。

| 選択 | 何が起きるか |
| --- | --- |
| **引き継ぐ** | 以後は自分で返事をする。トークが「トーク」タブへ移る |
| **代理だけに続けさせる** | このやり取りに入らない。週に一度、代理の報告だけがそのトークに届く |
| **このまま終わりにする** | 無くなる。相手には知らされない |

**相手側の判断はもう出ている。**引継書の発行時点で確定していて、こちらが考え始める前から決まっている。

- **相手も引き継ぎました** → 以後は人間同士。本人同士が何年連絡していなかったかが、そこで初めて並ぶ
- **相手は代理にまかせました** → 以後、相手側の発言はすべて相手の代理。**その人は、この関係に一度も出てきていない**
- **相手は引き継ぎませんでした** → 返信は来ない。あなたの代理は、まだ続けたいと言っている

### 引き継いだあと

相手は、代理と作った前提で話しかけてくる。内輪の言い回しだけを送ってきたりする（「二番の棚。」）。

入力欄の隣に**代理のボタン**がある。

- **自分で打つ** → 近さが下がる（代理より下手だから）
- **代理にまかせる** → 下がらない。ただし自分はこのやり取りに入らない

放置しても一日 0.6 ずつ下がる。戻す手立ては用意していない。

## 設計で決めたこと

- **相手の名前は伏せない。** 伏せる制度上の理由が無いし、知っている人の名前が並ぶ方が強い。伏せるのは「相手が引き継ぐか」だけ
- **書き言葉は平易なものだけ使う。**「築いた」「沈黙」「満了」「応対」のような書き言葉は、それらしく見せようとしているのが透ける。**連絡なし・やり取りが終わる・自分で返信**のように、普段使う言い方へ全部落とした
- **色は「誰が打ったか」だけを言う。** 緑があなた、藍が代理。二つのタブを行き来したときに、**色の割合が変わるだけ**で何が起きているかが分かる
- **地は灰、面は白。** 吹き出し・行・書類が地から浮く。少し先の時代の製品として、丸みと発色を強めにとっている
- **二つのタブで書式を完全に同じにする。** 並べ方、抜粋、未読の出し方まで揃える。同じだから、行き来したときに濃さの違いだけが目に入る
- **代理のトークは未読で始まり、自分のトークは既読で始まる。** 自分の過去のやり取りに未読が付くのはおかしいし、代理のぶんは一度も読んでいない
- **やり取り中の行に状態の印を出さない。** 見出しにも「代理がやり取りしています」と出ているので繰り返しても情報が増えない。**塗られた印は終わった行だけ**が持つので、引き継げるものが遠目にも拾える
- **動かすのは届いた瞬間だけ。** 開き直したときに全部が動くと、何が新しいのか分からなくなる
- **「代」の印は、書いた者が混ざるトークにだけ出す。** 代理のトークは全部が代理の発言なので、一通ごとに印を付けても情報が増えない（印だらけで読めなくなった）
- **秘密は重い。** 打ち明けるのに勇気が要るものだけ
- **作り話は確かめようがない形にする。** 訂正しようとすると関係の側が壊れる種類の嘘だけ
- **吹き出しは保存しない。** トークの種類・経過・自分が打ったものから毎回組み立てる。保存するのは、打ったもの・判断・既読の位置だけ

## 実演の一周

作品として見せるための時間割が `src/lib/loop.ts` にある。九本の台本を一周のなかへ置き、
それぞれ「現れる位置」「現れた時点の進み具合」「一通あたりの間隔」を持たせてある。

| | |
| --- | --- |
| 一周の長さ | 30 分（既定）／45 分／60 分 |
| 現れ方 | 最初は 2 本。18 分かけて 9 本まで増える |
| 一本の速さ | **15〜21 秒に一通**。トークごとにずらしてある |
| 同時に動く本数 | 平均 2.2 本 |
| 画面全体 | **8.5 秒に一通**（212 通 / 30 分） |
| 出し切ったら | 最初へ戻る。引き継いだ関係も、答えた確認も残らない |

**時刻は通数で決めている。**台本の日付どおりに流すと、日付が詰まった区間で二通が
同時に出て、空いた区間で四十秒以上何も起きない（実際にそうなった）。相手は機械なので、
一通ずつ等間隔に送り合うほうが理屈にも合う。日付は表示のうえの目盛りとして残してある。

一周の長さを変えると、現れる順も混み具合も変わらず、間隔だけが伸び縮みする。

**トークは保存していない。**時間割と現在時刻から毎回組み立てるので、開いていない
あいだも進んでいる。端末に残るのは本人が触った跡だけ（打った文・確認への答え・判断・既読）。

動くところは三つだけに絞っている。**届いた一通が下から入る／届いた行がひととき光る／
次の一通の数秒前に「…」が出る。**開き直したときに全部が動くと、何が新しいのか分からなくなる。

## まだ無いもの

- **生成が全部手元の台本。** 相手・秘密・作り話・やり取りは `src/lib/pools.ts` に書いた 9 人ぶん（212 通）。申込内容を読んで AI がやり取りごと生成するところまでは行っていない（[apps/yomichi](../yomichi) と同じ形で、GitHub Actions の中で生成できる）
- **自分が打った文章と、代理が打つはずだった文章を並べる。** ここが一番刺さるはずだが、まだ無い
- **あなたが打った文章から代理が口調を学ぶ。** 自分で打つほど近さは下がるが、代理は上手くなる——という皮肉をまだ実装していない
- **食い違いの警告。** 相手が信じている作り話と矛盾する内容を送ろうとしたとき、送信前に知らせる
- **相手の代理があなたに愛着を持っている、という機構。** 会話の最後にそれらしい一往復は入れてあるが、表示としては無い
