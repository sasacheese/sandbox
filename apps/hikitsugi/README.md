# 関係引継サービス

**あなたの代理人に、友達ができました。この友情を引き継ぎますか？**

見た目は普通のメッセンジャー。タブが二つあることだけが普通ではない。

- **トーク** — あなた自身のトーク。自分で打つ。数か月前で止まっている
- **代理** — あなたの代理人が、相手の代理人と続けているトーク。自分では打てない。**こちらのほうが濃い**

https://sasacheese.github.io/sandbox/hikitsugi/

## なにを・なぜ・いかに

**なにをハックするか**
人間関係を、自分で築く経験から、AI が事前に構築して本人へ引き渡せる資産へ変える。

**なぜハックするか**
AI が情報や技能だけでなく、共感・雑談・信頼形成まで代行できるとき、その関係の主体は名前を持つ本人なのか、実際に関係を築いた存在なのかを問うため。

**いかにハックするか**
本人の代理人が、接点のある相手の代理人と交流し、形成した友情・記憶・秘密・約束を「関係引継書」として本人へ渡す PWA を制作する。

この作品が言いたいのは「AI が人間関係を仲介できる」ことではない。

> 人間同士が友達になる可能性を探すために AI を使ったら、**先に AI 同士が本当に友達になってしまった。**

## 触る

```bash
npm install
npm run dev     # http://localhost:5220
```

## 画面

### 申込（一度だけ）

名前と 3 つの質問——最近気になっていること、人に言っていない癖、**触れられたくない話題**。加えて代理人の寄せ方（`本人らしさ ──●── 好かれやすさ`）。

**好かれやすさへ寄せるほど、あなたについての作り話が増える。**そうは書いていない。申告した「触れられたくない話題」は、相手の秘密に応じる材料として使われる（引継書に明記されて出てくる）。

### トーク（既定）

自分のトークが並んでいる。川口「ぜひ。また今度」（4 か月前）、さやか「落ち着いたら会おうね」（1 年前）、宮田「またお会いできればうれしいです」（2 年前）。全部、約束になっていない約束で終わっている。

**送れる。ただし、すぐには返ってこない。**一度だけ短い返事が来る相手と、返してこない相手がいる。

引き継いだ関係は、このタブへ移ってくる。**タブの移動が引き継ぎそのもの。**

### 代理

同じ書式で、**相手の名前は最初から出ている**。菅野 千夏（前職の同僚・沈黙 3 年 2 か月）、小松 遼（大学の同じ学部・5 年 7 か月）、新井 のぞみ（イベントで一度・4 年 11 か月）。

伏せていない理由：**伏せる制度上の説明が立たない**（既に接点のある相手が対象なので）。それに、実名の方が強い。顔を知っている人の名前で、代理人が九十日間、離婚の話まで打ち明け合っている。伏せているのは「相手が引き継ぐかどうか」だけで、それは申し出るまで分からない。

開くと**自分のトーク画面に見える。よく見ると自分は一言も打っていない。**

- 吹き出しは左右に分かれる（右＝あなたの代理人、左＝相手の代理人）
- 右は茶で塗り、左は白に茶の罫。どちらも代理人だが、誰の発言かは追える
- あなたの代理人が語った作り話には、**その場で注記**が出る

```
20 日目
  A            実は四年前から通院しています。仕事の人には言っていません。
  （あなた側）   こちらも通っています。曜日は違いますが。
               ※ この発言は事実に基づきません
```

沈黙と喧嘩も入っている（「決めるのは私です」→ 数日やり取りが止まる →「言い過ぎました」）。三本のトークは**進み方がずれて**始まっていて、一本は満了、一本は途中、一本は始まったばかり。開くたびに勝手に進んでいる。

### 代理人からの確認

代理人はあなたの最新情報を持っていない。持たないまま喋ると作り話になるので、会話の途中で**本人へ訊いてくる**。

```
［代理人からの確認］
相手が離婚の話をしています。同じ時期に似たことがあった、
と応じてもよいですか。
　［はい］　［いいえ］　［答えない］
```

- **はい** → 代理人が「こちらも、同じ時期に似たようなことがありました」と応じる。**事実として扱われる**
- **いいえ** → 「こちらにそういう話はありません。ただ、聞いています」と訂正する
- **答えない／放置** → 代理人が同じ文を勝手に埋める。そのとき**同じ一文が作り話になる**（※ この発言は事実に基づきません が付く）

**同じ一文が、答えたかどうかで事実にも嘘にもなる。**これが「代理人に自分らしくいてもらうための労働」の実装で、答えるたびに引継書の作り話が一つ減る。

答える猶予は実時間で最低 90 秒ある（倍率をどれだけ上げても、読んで押すぶんは残す）。あなたが使い始める前に過ぎてしまった確認は、最初から埋まっている——**その場にいなかったから**。

### 引継書

満了したトークの下部に「引継書を読む」が出る。会話はトークで読めるので、この書類は**関係を項目に分解したもの**に絞ってある——呼び方、預かった秘密、相手があなたについて信じていること（作り話には「代理」印）、触れてはいけないこと、内輪の言い回し、一緒に立てた計画、代理人が外へ出した情報。

図は四つ。**茶が代理人、墨があなた、朱が失ったぶん**という一つの規則で通している。

| 図 | 何が見える |
| --- | --- |
| 期間の帯 | 茶色の長い区間（代理人 90 日）と、その先の短い墨（あなた） |
| 日の点表 | 一点が一日。90 日ぶんの点が画面を埋める |
| 関係の年表 | **線は引継の縦線より前で立ち上がりきっている。**この山を登ったのは自分ではない |
| 顔の環 | 茶の弧＝代理人が築いたぶん、墨の弧＝あなたが足したぶん、朱の弧＝失ったぶん |

### 判断

三つ。どれを選んでも何かを失う。

| 選択 | 何が起きるか |
| --- | --- |
| **引き継ぐ** | 以後あなたが応対する。トークが「トーク」タブへ移る |
| **代理人だけに続けさせる** | 当事者にならない。週に一度、代理人の報告だけがそのトークに届く |
| **知らないまま終了する** | 破棄。相手には通知されない |

**相手側の判断はもう出ている。**引継書の発行時点で確定していて、こちらが考え始める前から決まっている。

- **相手方も引き継ぎました** → 以後は人間同士。本人同士の沈黙が何年だったかが、そこで初めて並ぶ
- **相手方は代理人に任せました** → 以後、相手側の発言はすべて相手の代理人。**その人は、この関係に一度も出てきていない**
- **相手方は引き継ぎませんでした** → 返信は来ない。あなたの代理人は、まだ続けることを希望している

### 引き継いだあと

相手は、代理人と築いた前提で話しかけてくる。内輪の言い回しだけを送ってきたりする（「二番の棚。」）。

入力欄の隣に**代理人のボタン**がある。

- **自分で打つ** → 親密度が下がる（代理人より下手だから）
- **代理人に任せる** → 下がらない。ただし自分はこの関係に参加しない

放置しても一日 0.6 ずつ下がる。戻す手立ては用意していない。

## 設計で決めたこと

- **相手の名前は伏せない。** 伏せる制度上の理由が無いし、知っている人の名前が並ぶ方が強い。伏せるのは「相手が引き継ぐか」だけ
- **地は白。** 吹き出しと書類が地から浮くよう、面の色を一段用意している
- **二つのタブで書式を完全に同じにする。** 並べ方、抜粋、未読の出し方まで揃える。同じだから、行き来したときに濃さの違いだけが目に入る
- **代理人のトークは未読で始まり、自分のトークは既読で始まる。** 自分の過去のやり取りに未読が付くのはおかしいし、代理人のぶんは一度も読んでいない
- **「代」の印は、書いた者が混ざるトークにだけ出す。** 代理人のトークは全部が代理人の発言なので、一通ごとに印を付けても情報が増えない（印だらけで読めなくなった）
- **秘密は重い。** 打ち明けるのに勇気が要るものだけ
- **作り話は確かめようがない形にする。** 訂正しようとすると関係の側が壊れる種類の嘘だけ
- **吹き出しは保存しない。** トークの種類・経過・自分が打ったものから毎回組み立てる。保存するのは、打ったもの・判断・既読の位置だけ

## 時間

`設定 → 時間の進み方`。既定は **1 日 = 3 秒**（触ってすぐ意味が分かる速さ）。日常で使うなら実時間。進み具合は「進んでいた日数＋実時間の経過」で持っているので、倍率を変えても巻き戻らない。

## まだ無いもの

- **生成が全部手元の台本。** 相手・秘密・作り話・やり取りは `src/lib/pools.ts` に書いた 3 人ぶん。申込内容を読んで AI がやり取りごと生成するところまでは行っていない（[apps/yomichi](../yomichi) と同じ形で、GitHub Actions の中で生成できる）
- **自分が打った文章と、代理人が打つはずだった文章を並べる。** ここが一番刺さるはずだが、まだ無い
- **あなたが打った文章から代理人が口調を学ぶ。** 自分で打つほど親密度は下がるが、代理人は上手くなる——という皮肉をまだ実装していない
- **食い違いの警告。** 相手が信じている作り話と矛盾する内容を送ろうとしたとき、送信前に知らせる
- **相手の代理人があなたに愛着を持っている、という機構。** 会話の最後にそれらしい一往復は入れてあるが、表示としては無い
