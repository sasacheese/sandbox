# 関係引継サービス

**あなたの代理に、友達ができました。この友情を引き継ぎますか？**

見た目は普通のメッセンジャー。**設定のなかに、実験機能のトグルが一つある**だけが普通ではない。

https://sasacheese.github.io/sandbox/hikitsugi/

## なにを・なぜ・いかに

**なにをハックするか**
人間関係を、自分で作る経験から、AI が先に作って本人へ引き渡せる資産へ変える。

**なぜハックするか**
AI が情報や技能だけでなく、共感・雑談・信頼づくりまで代行できるとき、その関係の持ち主は名前を持つ本人なのか、実際にやり取りをした存在なのかを問うため。

**いかにハックするか**
既存のメッセンジャーに**あと一歩だけ足した実験機能**として実装する。トーク履歴を取り込み、しばらく連絡していない相手に代理が声をかけ、続き、そこで出来た友情・記憶・秘密・約束を「引継書」として本人へ渡す。

この作品が言いたいのは「AI が人間関係を仲介できる」ことではない。

> 人間同士が友達になる可能性を探すために AI を使ったら、**先に AI 同士が本当に友達になってしまった。**

## これは、どこまでが実在か

**空想は一歩ぶんしかない。**残りはすでに出荷されているか、法律になっている。

| | いまの現実 | この作品 |
| --- | --- | --- |
| AI があなたの返信を書く | **もうある。**LINE「AIトークサジェスト」（2025-04・LINE Labs のオプトイン・1対1のみ・300回/日）。生成に使うのは**そのトークルーム内の直近のトーク履歴**。2026-04 に Yahoo! のアシスタントと統合して「Agent i」に | 同じ | 
| AI が代わりに送る・続ける | 提案までで止まっている | **ここだけが一歩先** |
| 相手にも AI がいる | A2A プロトコルが 2026-01 に v1.0.0。署名つき Agent Card で相手のエージェントを検証する | 同じ |
| AI だと相手に伝える | **義務。**EU AI 法 第50条が 2026-08-02 から適用。最初のやり取りの時点で明示しなければならない | 守る（後述） |
| AI が現実の出来事を知る | 接続したアカウント（WhatsApp は 2026-07 にカレンダー・メール連携、1対1のトークにメモリ） | **接続しない。**過去ログだけ |

需要のほうも作っていない。

```
55.9%  連絡を取りたいが、声をかけづらい人がいる
41.3%  声をかけづらい理由の一位「どう切り出せばいいかわからない」
59.2%  久しぶりに連絡が来たら「嬉しい」
                          ——LINEヤフー調べ（2025年8月・15〜69歳・n=737）
```

**この機能は、実在する困りごとに答えている。**答えているからこそ、行き過ぎが際立つ。

## 「AI がなぜか知っている」を消す

いちばん嘘くさいのは、AI が過去のやり取りや近況をなぜか把握していることだった。そこを制度で塞いだ。

### 1. 知識の入口は、取り込んだ履歴だけ

最初の画面は**トーク履歴の取り込み**。LINE の「トーク履歴を送信」が吐く .txt を読む（実在の機能・実在の書式）。読み込むと、**集計するだけで**この表が出る。

```
戸田 亮      2015/5/2    4139 日前    6 通
相良 郁子    2018/6/1    3013 日前    5 通
桜井 まりえ  2020/8/5    2217 日前    7 通
…
川口         2026/4/27    126 日前    4 通
```

名前も訊かない。**書き出しの中にもう書いてある**（全部の履歴に共通して出てくる送信者が自分）。自分の .txt を選んでもいいし、同梱の見本 12 件で試してもいい。どちらでも端末の外へは出ない。あとから `設定 → トーク履歴を足す` で増やせる（同じ相手のものは差し替え）。

### 取り込んだ相手との代理のやり取りを、履歴から作る

手書きの九人は見本で、**自分の履歴を取り込んだ相手には台本が無い**。友達の一覧に「この人との代理のやり取りを作る」が出る。押すと、その人の過去ログと自分の表示名**だけ**をモデルへ渡して、90 日ぶんの台本を一回で作る。

- 鍵は GitHub の repo secret `OPENAI_API_KEY`（モデル名は variable `OPENAI_MODEL`）から、**ビルド時に束ねる**。設定画面には出さない。ブラウザから直接モデルの API を呼び、こちらのサーバは無い
- **束ねた鍵は配信物に入るので、公開サイトから読める。**入口の合言葉は JS の取得を止めないので、守りにはならない。**使用量の上限を付けた鍵**にすること。ちゃんと隠すなら、鍵を持つ小さな中継（Cloudflare Workers など）を一枚挟む
- 作った台本は他の九人と同じ時間割で流れる。作った瞬間の位置から現れて、一通ずつ届き始める
- 返ってきた JSON は厳しく検査する。**出どころが「履歴」なのに履歴に無い文を引いていれば「文体」へ落とす。**引用は、過去ログに実在する一通でなければならない。日付が壊れていれば作らない——壊れた台本で始めるより、無いほうがいい

つまり、自分の実際の LINE の書き出しを食わせると、**自分の書き方を真似た代理が、実際に話さなくなった相手と 90 日ぶん話す**。

### 2. 発言ごとに、出どころが付く

代理が知っていることの出どころは五つしかない。**そのうち一つだけが作り話。**

| 印 | 出どころ |
| --- | --- |
| **履歴** | 過去ログに書いてあった。**引いた一通をそのまま出せる** |
| **本人** | あなたが確認に答えた |
| **相手** | 相手の代理から聞いた |
| **文体** | 事実は言っていない。あなたの書き方へ寄せただけ |
| **推測** | どれでもない ← **これだけが作り話** |

会話の見出しの「出所」を押すと、全部の吹き出しに札が出る。既定では隠してある——**本物の製品なら、こんなものは既定で出さない。**

```
代理  三年同じ階にいたのに、一度も話しかけられませんでした。
      退職のご挨拶が最後でしたね。
      ［履歴］「三年間ありがとうございました。同じ階だったのに、ほ…」から
```

### 3. 代理は「最後のやり取り」より後を知らない

トークの上に、知識の範囲がそのまま出る。

```
代理が読んだもの  このトークの過去ログ 6 通（〜2023/7/3）
これより後のことは知りません。
```

だから訊いてくる。**「代理からの確認」に、ここで初めて理由がついた。**

```
［代理からの確認］
2023/07/03 より後のことは、過去ログにありません
相手が離婚の話をしています。同じ時期に似たことがあった、と応じてもよいですか。
　［はい］　［いいえ］　［代理にまかせる］
```

- **はい／いいえ** → 出どころが「本人」になる
- **代理にまかせる／放置** → 代理が同じ文を埋める。**出どころが「推測」になる**——同じ一文が作り話に変わる

### 4. 開示は、守る

第50条に従う。一日目にシステム行が立つ。

```
── このトークは自動応答です。相手側も同じです。（AI法 第50条）
2 日目
   代理  三年同じ階にいたのに、一度も話しかけられませんでした。
```

そして六十日目、相手は離婚の話をしている。**開示はされている。誰も見ていない。**黙って騙すより、Cookie バナーと同じこの形のほうが、実際に起きることだと思う。

### 5. 相手も使っていないと始まらない

代理を出せるのは、相手も同じ実験機能をオンにしている人だけ。友達一覧には「未対応」が並ぶ。

> **川口**（連絡なし 4 か月）　未対応
> この人は代理応答を使っていません。招待するまで代理は出せません。

**いちばん連絡しやすい相手ほど、この機能では触れない。**

## 画面

タブが四つ。**友達・トーク・代理・設定。**

### 代理とのトーク

トークの一番上に、**自分の代理とのトーク**が固定されている。代理は「**あなたのフリをして連絡する役**」——友達に「あんた連絡するの得意だから、私のフリしてやり取りしといて」と頼んだ、あの関係。だから口調は敬語ではなく、頼まれた友達のもの。顔は**あなたの顔を少しずらして重ねたクローン**で、誰の代理かがひと目で分かる。

**代理は自分から言ってくる。**

```
代理  たつや、代理だよ。トーク履歴 12 件、読ませてもらった。しばらく連絡してない
      人たちに、私がたつやのフリして声かけてみるね。…分からないことがあったら、
      その都度こっちから聞くから。

代理  菅野さんに声かけてみた。返ってきたよ。

代理  ［これ、どうする？］
      菅野さんから離婚の話きた。私も同じ時期に似たことあったって言っていい？
      　［はい］　［いいえ］　［まかせる］

代理  菅野さんの件、返事なかったから「こちらも、同じ時期に似たようなことが
      ありました。」って言っといた。違ってたら言って。

代理  菅野さんとのやり取り、一区切りついた。引継書まとめといたから、代理タブから見て。
```

「これ、どうする？」は、相手のトークにある「代理からの確認」と**同じ札**。ここで答えれば向こうも埋まる。過去ログに無いことに触れたとき、代理は必ずここへ訊きに来る——**返事が無ければ勝手に言い、そのことも言ってくる**。

こちらからの指示は規則で読む。名前（姓だけ・名だけ・敬称つき）と動詞で**止める・再開する**。止めるとそのトークの時計が止まり、再開しても飛ばない。読めないものは覚えておき、引継書の注意事項に「本人からの申し送り」として載る。

> **あなた** 菅野さんには返さないで
> **代理** オッケー、菅野さんにはもう送らないでおく。向こうには言わないよ。

代理は「了解」を言うが、**何を理解したかは必ず言い直す**——それが唯一の、指示が通ったかどうかの確認になる。指示は一周が終わっても消えない。

### 友達

LINE の「ホーム」に寄せてある。いちばん上に自分の行（履歴から分かった名前）、その下に集計、それから折りたためる群——代理がやり取り中／引き継げます／引き継いだ／友だち／終わった。白い面と薄い罫で、カードは使わない。

集計に、この作品でいちばん短い言い方が出る。

```
● 自分で話している 0        ● 代理が話している 9
12 人のうち、この 30 日にあなたが自分でやり取りしたのは 0 人です。
```

左の数字は取り込んだ履歴からの計算で、**最初から 0 のことがある**。右だけが、眺めているあいだに増えていく。自分で一通送れば左が 1 になる——手当てはそれだけ。

代理が動いている相手は、顔に**藍の環**（やり取りの進み具合。閉じたら引き継げる）と「代」の印が付く。

### トーク

取り込んだ履歴がそのまま並ぶ。作り物ではないので、止まっているのも、最後の一通が約束になっていないのも、こちらの都合ではない。

> 川口「ぜひ。また今度」（4 か月）／さやか「落ち着いたら会おうね」（1 年 1 か月）／菅野 千夏「はい。落ち着いたらぜひ」（3 年 2 か月）

送れる。ただし、すぐには返ってこない。引き継いだ関係は、このタブへ移ってくる。**タブの移動が引き継ぎそのもの。**

### 代理

オンにするまでは、機能の紹介しか出ていない（上の統計はここに載っている）。オンにすると、**同じ名前のトークがもう一つ現れる**——片方は自分のもので数年前に止まっていて、もう片方は代理のもので、いま動いている。

色の規則は一本だけ。**誰が打ったかを色で言う。**

| | |
| --- | --- |
| 緑 | あなたが打った |
| 藍 | 代理が打った |
| 白 | 相手の人間が打った |
| 薄藍 | 相手の代理が打った |

つまり**画面が藍で埋まっているあいだ、そこに人間はいない。**引き継ぐと緑が混じりはじめる。

### 引継書

やり取りが終わったトークの下部に「引継書を読む」が出る。**出どころ付きの記録**になっている。

```
相手があなたについて信じていること
  履歴  あなたが「そうだったんですね。お疲れさまでした」と書く人であること
  履歴  「はい。落ち着いたらぜひ」と言ったまま、そのままにしていること
  推測  あなたにも同じ時期に離婚があったこと

代理が外へ出した情報
  履歴  返信までに 38 分ほどかかること
  履歴  一通が平均 15 文字と短いこと
  履歴  文の終わりに句点を打たないことが多いこと
  推測  あなたがいま、連絡を取れる状態にあること
```

**返信の速さも、文の長さも、句点の癖も、過去ログを数えれば出る。**気味が悪いのは、どれも当たっているからで、当たっているのは計算だからだ。推測はひとつだけ——それが無いと会話が始まらないもの。

図は四つ。**藍が代理、緑があなた、桃が失ったぶん**という一つの規則で通している。

### 判断

三つ。どれを選んでも何かを失う。**相手側の判断はもう出ている**（引継書の発行時点で確定していて、こちらが考え始める前から決まっている）。

| 選択 | 何が起きるか |
| --- | --- |
| **引き継ぐ** | 以後は自分で返事をする。トークが「トーク」へ移る |
| **代理だけに続けさせる** | このやり取りに入らない。週に一度、代理の報告だけが届く |
| **このまま終わりにする** | 無くなる。相手には知らされない |

引き継いだあと、自分で打つと近さが下がる（代理より下手だから）。放置しても下がる。戻す手立ては用意していない。

## 実演の一周

作品として見せるための時間割が `src/lib/loop.ts` にある。一周の長さは `設定 → デモ用設定`（設定のいちばん最後。作品の外側の都合なので、いちばん目立たない場所に置いてある）。九本の台本を一周のなかへ置き、それぞれ「現れる位置」「現れた時点の進み具合」「一通あたりの間隔」を持たせてある。

| | |
| --- | --- |
| 一周の長さ | 30 分（既定）／45 分／60 分 |
| 現れ方 | 最初は 2 本。18 分かけて 9 本まで増える |
| 一本の速さ | **15〜21 秒に一通**。トークごとにずらしてある |
| 同時に動く本数 | 平均 2.2 本 |
| 画面全体 | **8.5 秒に一通**（212 通 / 30 分） |
| 出し切ったら | 最初へ戻る。引き継いだ関係も、答えた確認も残らない |

時刻は**通数で決めている**。台本の日付どおりに流すと、日付が詰まった区間で二通が同時に出て、空いた区間で四十秒以上何も起きない。相手は機械なので、一通ずつ等間隔に送り合うほうが理屈にも合う。

動くところは三つだけ。**届いた一通が下から入る／届いた行がひととき光る／次の一通の数秒前に「…」が出る。**

デモ用設定には、もう一つ治具がある。**「引き継いだ状態から始める」**——相手を一人押すと、その場で引き継ぎ済みになってトークへ移る。やり取りは出し切った状態で、相手側がどうしたかは決めない（引継書を通っていないので、相手の判断を見る機会が無い）。引き継いだ後を一回試すのに一周待たなくてよいようにするためのもので、一周が終わると元に戻る。

## 設計で決めたこと

- **サービスではなく、設定のなかの実験機能にする。** LINE が AIトークサジェストを LINE Labs のオプトインで出したのと同じ形。この形にした途端、「なぜ履歴を読めるのか」「なぜ相手にも代理がいるのか」「なぜ開示があるのか」の説明が全部いらなくなった。**恐ろしいことは、設定画面のベータのトグルとしてやって来る**
- **入力欄を作らない。** 名前も、相手も、接点も、沈黙の長さも、取り込んだ .txt から出る。訊くのは「代理の書き方」だけ
- **知識の範囲を画面に出す。** 代理が読んだ通数と最後の日付をトークの上に置く。**知らないことを知らないと言える**ようにしないと、全部が嘘くさくなる
- **書き言葉は平易なものだけ使う。**「築いた」「沈黙」「満了」「応対」のような語は、それらしく見せようとしているのが透ける。連絡なし・やり取りが終わる・自分で返信、へ全部落とした
- **色は「誰が打ったか」だけを言う。** 緑があなた、藍が代理
- **相手の名前は伏せない。** 伏せる制度上の理由が無い。伏せるのは「相手が引き継ぐか」だけ
- **二つのタブで書式を完全に同じにする。** 同じだから、行き来したときに濃さの違いだけが目に入る
- **秘密は重い。** 打ち明けるのに勇気が要るものだけ
- **作り話は確かめようがない形にする。** 訂正しようとすると関係の側が壊れる種類の嘘だけ
- **トークは保存しない。** 保存するのは取り込んだ過去ログと、本人が触った跡（打った文・確認への答え・判断・既読）だけ

## まだ無いもの

- **代理の返事が規則。** 代理とのトークの返事は、止める・再開する・申し送るの三つの型文。鍵があるときはモデルに言わせたほうが自然になるが、まだ繋いでいない
- **生成した台本の質が、モデル次第。** 検査で壊れたものは落とすが、平板なものは通る。手書きの九人と並べると差が出る
- **自分が打った文章と、代理が打つはずだった文章を並べる。** ここが一番刺さるはずだが、まだ無い
- **あなたが打った文章から代理が口調を学ぶ。** 自分で打つほど近さは下がるが、代理は上手くなる——という皮肉をまだ実装していない
- **食い違いの警告。** 相手が信じている作り話と矛盾する内容を送ろうとしたとき、送信前に知らせる
- **招待。** 「未対応」の相手に招待を送る導線が、いまは文言だけ
