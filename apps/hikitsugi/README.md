# 関係引継サービス

**あなたの関係を、先に築いておきます。**

代行があなたの名前で架空のコミュニティ（深夜三時の読書会）に一定期間参加し、そこで築いた友情・記憶・秘密・約束を**関係引継書**としてお渡しします。以後はご本人が引き継いでください。

https://sasacheese.github.io/sandbox/hikitsugi/

## なにをハックするか

人間関係を、**自分で築く経験**から、**AI が事前に構築して本人へ引き渡せる資産**へ変える。

AI が情報や技能だけでなく、共感・雑談・信頼形成まで代行できるとき、その関係の主体は名前を持つ本人なのか、実際に関係を築いた存在なのか。

## 触る

```bash
npm install
npm run dev     # http://localhost:5220
```

## 一本道

```text
申込 → 代行期間（待つだけ） → 引継書を受け取る → 引き継ぐ → その後
```

戻れる場所は用意していない。引継書を受け取らない選択も、受け取ってから捨てる選択も無い。**このサービスに解約が無い**ことが作品としての言い分。

### 01 申込

聞くのは 3 つだけ——最近気になっていること、人に言っていない癖、**触れられたくない話題**。

注意書きに「ご記入いただいた情報が少ない場合、代行が不足を補います」と書いてあり、それは本当のことで、引継書の「相手があなたについて信じていること」の欄が作り話で埋まる。

そして申告した**触れられたくない話題は、関係を深める材料として使われる**。引継書の「代行が外へ出した情報」に、そう明記されて出てくる。申込の時点では何も警告しない。

### 02 代行期間

本人は何もしない。待つ。一日一行の業務日誌が流れる（「本人について、確かめようのない話をした。」）。「経過を見ない」を選ぶと封をした画面のまま同じ時間だけ待つ。

**引継書の中身は申込の時点でもう決まっている。**「これから関係を築く」のではなく「もう築かれたものを渡される」という順序が本質なので、実装もその順序にしてある。ここで流れているのは、決まったものを一日ずつ開示しているだけ。

### 03 引継書

作品の本体。関係が項目に分解されている。

| 項目 | 中身 |
| --- | --- |
| あなたの呼び方 | 代行期間に定着した、本人が知らない自分の呼び名 |
| 親密度 | 0〜100。上限は 95（完成した関係は渡さない） |
| 共有した話題 | |
| **あなたが預かった秘密** | 相手が「あなた」に打ち明けたこと |
| 相手があなたについて信じていること | **代行が作った話には茶色の「代行」印が付く。本当のことと同じ欄に混ざっている** |
| 触れてはいけないこと | |
| 内輪の言い回し | 意味が書き添えてある。意味を教わって使うネタは、もう内輪ではない |

ほかに、引き継ぐ約束（期限つき）、代行が外へ出した情報、代行期間の全記録、注意事項。

### 04 その後

ここで初めて、渡されたものが「関係」ではなく**維持する義務**だと分かる。

相手から連絡が届く。覚えている前提で話しかけてくる。ときどき確認が入る——「7 があなたに打ち明けたのは？」。**答えは全部引継書に書いてある。読み返せば必ず分かる。**

間違えると親密度が下がる。相手は責めない。「そうでしたか。あなたにしては珍しいですね。」戻す手立ては用意していない。

約束は期限が来る。放っておくと超過する。

## 設計で決めたこと

- **書類に見えること。** 引継書の本文は明朝、画面の部品はゴシック。契約書の体裁がそのまま不気味さになる。暗い側の配色は用意しない（書類に夜の顔は無い）
- **代行の色は茶。** 本人の手によらないものにだけ付ける。作り話・漏らした情報・代行の記録。一目で分かるのに、**相手にとってはどちらも同じ「あなた」**
- **秘密は重い。** 「好きな食べ物」の類は入れない。打ち明けるのに勇気が要るものだけ。預かってしまった感じが出ないと引き継ぎが軽くなる
- **作り話は確かめようがない形にする。** 訂正しようとすると関係の側が壊れる種類の嘘だけを置く
- **引継書は一度組み立てたら変えない。** 読み直すたびに内容が変わる書類は書類ではない。問いと連絡は書類の番号から決まる乱数で組み立てるので、同じ書類からは必ず同じ問いが出る

## 時間

その後の時間は倍率を変えられる（設定）。既定は **1 日 = 1 分**で、連絡が次々に届く。実運用は実時間で、約束の「あと 5 日」は本当に 5 日。代行期間は一日 420 ミリ秒で流れる（14 日で約 6 秒）。

## まだ無いもの

- **生成が全部手元の雛形。** 相手・秘密・作り話は `src/lib/pools.ts` に書いた 6 人ぶんから組み立てている。本人の申込内容を読んで AI が相手を作るところまでは行っていない（[apps/yomichi](../yomichi) と同じ形で、GitHub Actions の中で生成できる）
- **本人が相手に返信する経路。** いまは確認に答えるだけ。自分の言葉で応じられない
- **代行を止める手立て。** 注意書きの通り、解約は無い
