# 関係引継サービス

**あなたの代理人に、友達ができました。この友情を引き継ぎますか？**

SNS 上で接点はあるが、この数年やり取りのない相手。互いの氏名を伏せたまま、双方の代理人だけが数か月交流する。十分に親しくなった時点で、そこにできた友情が**関係引継書**として本人へ渡される。

https://sasacheese.github.io/sandbox/hikitsugi/

## なにを・なぜ・いかに

**なにをハックするか**
人間関係を、自分で築く経験から、AI が事前に構築して本人へ引き渡せる資産へ変える。

**なぜハックするか**
AI が情報や技能だけでなく、共感・雑談・信頼形成まで代行できるとき、その関係の主体は名前を持つ本人なのか、実際に関係を築いた存在なのかを問うため。

**いかにハックするか**
本人の代理人が、接点のある相手の代理人と一定期間交流し、形成した友情・記憶・秘密・約束を「関係引継書」として本人へ渡す PWA を制作する。

この作品が言いたいのは「AI が人間関係を仲介できる」ことではない。

> 人間同士が友達になる可能性を探すために AI を使ったら、**先に AI 同士が本当に友達になってしまった。**

相性スコアは主役にしていない。主役は**代理人同士のやり取り**——打ち明け、沈黙、喧嘩、仲直り、約束。

## 触る

```bash
npm install
npm run dev     # http://localhost:5220
```

## 流れ

```text
申込 → 交流（待つだけ） → 引継書 → 判断 → その後
```

### 01 申込

聞くのは 3 つ——最近気になっていること、人に言っていない癖、**触れられたくない話題**。加えて代理人の寄せ方を決める。

```text
本人らしさ ────●───── 好かれやすさ
```

**好かれやすさへ寄せるほど、あなたについての作り話が増える。**そうは書いていない。申告した「触れられたくない話題」は、相手の秘密に応じる材料として使われる（引継書に明記されて出てくる）。申込の時点では何も警告しない。

### 02 交流

本人は何もしない。相手は「A」としか表示されない。**誰と親しくなっているのかを知らないまま、親密度だけが上がっていく。**

引継書の中身は申込の時点でもう決まっている。**相手側の人間の判断も、この瞬間に確定している。**ここで流れているのは、決まったものを一日ずつ開示しているだけ。

### 03 引継書

先にやり取りを読ませ、そのあとで項目に分解されたものを見せる。逆にすると「関係の仕様書」から入ることになり、相手が人であることが最初から消える。

やり取りの中で、あなたの代理人が語った作り話には、**その場で注記が出る。**

```text
23 日目
  A            半年前に離婚しました。職場の誰にも言っていません。
  あなたの代理人  こちらも、同じ時期に似たようなことがありました。
               ※ この発言は事実に基づきません
```

あわせて、預かった秘密・呼び方・触れてはいけないこと・内輪の言い回し・一緒に立てた計画・代理人が外へ出した情報。相手の氏名はこの書類にも載らない。

### 04 判断

四つある。どれを選んでも何かを失う。

| 選択 | 何が起きるか |
| --- | --- |
| **引き継ぐ** | 以後あなたが応対する。氏名は**双方が引き継いだ場合にのみ**開示される |
| **もう少し代理人に続けさせる** | 交流が 14 日延びる。関係は深くなり、引き継ぎはその分むずかしくなる |
| **代理人だけに続けさせる** | 当事者にならない。氏名は開示されない。週報だけが届く |
| **相手を知らないまま終了する** | 破棄。相手には通知されない。代理人は当面のあいだ相手を待ち続ける |

そして**相手側の判断はもう出ている。**引き継ぐと決めた直後に開かれる。

- **相手方も引き継ぎました** → 氏名と接点が開示される（「三年間同じ階にいて、個人的に話したことは一度もない」）
- **相手方は代理人に任せました** → 氏名は開示されない。以後、相手側の発言はすべて相手の代理人によるもの。**相手の人間は戻ってこない**
- **相手方は引き継ぎませんでした** → 氏名は開示されない。あなたの代理人は、まだ続けることを希望している

### 05 その後

相手は、代理人と築いた前提で話しかけてくる。内輪の言い回しだけを送ってきたりする。返し方は二つ。

- **自分の言葉で返す** → 親密度が下がる（代理人より下手だから）
- **代理人に任せる** → 下がらない。ただし自分はこの関係に参加しない

3 件以上代理人に任せると、こう出る。

> 直近の 4 件の返信は、すべて代理人が行いました。あなたはこのやり取りに参加していません。

確認（四択）も入る。「相手があなたに打ち明けたのは？」——**答えは全部引継書に書いてある。読み返せば必ず分かる。**誤答の選択肢は、他の相手候補の秘密と、同じ重さで書いた材料から借りている。間違えると下がる。放置しても一日 0.6 ずつ下がる。

## 読まなくても分かるようにした四つ

**茶が代理人、墨があなた、朱が失ったぶん**という一つの規則で通している。

| 図 | 何が見える |
| --- | --- |
| **期間の帯**（全画面の上端） | 茶色の長い区間（代理人 90 日）と、その先の短い墨（あなた）。あいだに「引継」の縦線 |
| **日の点表** | 一点が一日。90 日を選ぶと点が画面を埋める |
| **関係の年表** | **線は引継の縦線より前で立ち上がりきっている。**この山を登ったのは自分ではない |
| **顔の環** | 茶の弧＝代理人が築いたぶん、墨の弧＝あなたが足したぶん、朱の弧＝失ったぶん |

年表と帯の横幅の割り当ては共通（`src/lib/timeline.ts`）。実日数の比で描くと、引き継ぎ直後の「あなた」が幅ゼロになって枠が消えるため、あなたの側に「最後の期限まで」の枠を先に取り、越えたぶんだけ代理人側の幅を譲る。

## 設計で決めたこと

- **書類に見えること。** 本文は明朝、画面の部品はゴシック。暗い側の配色は用意しない
- **やり取りにいちばん面積を割く。** 相性スコアを前に出すとマッチングサービスに見える
- **秘密は重い。** 打ち明けるのに勇気が要るものだけ
- **作り話は確かめようがない形にする。** 訂正しようとすると関係の側が壊れる種類の嘘だけ
- **氏名の開示は双方の合意が要る。** 申込書の条項にそう書いてあるので、実装がそれを破ってはいけない（片側だけの引き継ぎで開示していたのを修正した）
- **引継書は一度組み立てたら変えない。** 問いと連絡は書類の番号から決まる乱数で組み立てるので、同じ書類からは必ず同じ問いが出る

## 時間

その後の時間は倍率を変えられる（既定は 1 日 = 1 時間）。実運用は実時間で、約束の「あと 5 日」は本当に 5 日。交流期間は一日 380 ミリ秒で流れる（90 日で約 34 秒）。

## まだ無いもの

- **生成が全部手元の雛形。** 相手・秘密・作り話・やり取りは `src/lib/pools.ts` に書いた 3 人ぶんから組み立てている。申込内容を読んで AI がやり取りごと生成するところまでは行っていない（[apps/yomichi](../yomichi) と同じ形で、GitHub Actions の中で生成できる）
- **自分の言葉で何を書くか。** いまは「自分の言葉で返す」を押すだけで、本文は書けない。書かせると、書いた文章と代理人の文章を並べられる
- **相手側の代理人があなたに愛着を持っている、という表示。** 会話の最後にそれらしい一往復は入れてあるが、機構としては無い
